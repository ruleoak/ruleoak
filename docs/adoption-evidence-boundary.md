# Adoption evidence boundary

RuleOak can measure some local activation and safety signals without uploading project data, but source code and local tests cannot establish external adoption.

## Source-verifiable evidence

The repository can verify deterministic policy/evidence behavior, one-use authority, effect-verification failure handling, parser hardening, reproducible packaging, licensing consistency, local qualification and privacy-safe aggregate report generation.

## External evidence

Independent installation success, time to first useful protected action, repeat use, real Effect Profile coverage, security review, user-reported usefulness and retention must be observed outside the source archive.

RuleOak must not turn unmeasured external outcomes into source-level PASS claims. Local adoption snapshots are review-before-share artifacts and are never uploaded automatically.
