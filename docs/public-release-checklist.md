# RuleOak public release checklist

- [ ] `npm run qualify` passes from a clean source extraction.
- [ ] Source manifest, package metadata, licensing and public/private-boundary checks pass.
- [ ] GitHub Actions use immutable action pins and the supported Node.js matrix.
- [ ] Release candidate hashes and manifest reproduce from a clean environment.
- [ ] `SECURITY.md`, contribution guidance, governance and trademark policy are current.
- [ ] Public documentation matches the exact release behavior and version.
- [ ] Source-tested, native-tested, device-tested and external/not-run evidence remain clearly separated.
- [ ] No unpublished planning material, private paths, owner-only instructions, or non-public release history ships in the public source.
- [ ] Public npm/repository links are enabled only after the corresponding external endpoint actually exists.
