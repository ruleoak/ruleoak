# RuleOak v0.50 release readiness

RuleOak v0.50.0 is a public developer preview, not a 1.0 compatibility promise or security certification.

Current source qualification covers public API stability, authority/evidence contracts, supported MCP boundaries, Effect Boundary behavior, release reproducibility, licensing, package metadata and repository security hygiene.

The following gates remain open before any 1.0 decision:

1. meaningful external adoption and compatibility feedback;
2. independent security review and remediation;
3. demonstrated protocol stability across independent implementations;
4. production experience sufficient to validate the stable-surface choices.

Passing v0.50 qualification means the source artifact satisfies its current declared contracts and checks. It is not a security certification, production guarantee, or 1.0 readiness declaration.
