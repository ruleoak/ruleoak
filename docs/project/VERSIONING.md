# Versioning

RuleOak remains pre-1.0.

- patch: compatible bug/security correction;
- minor: new capability and potentially breaking pre-1.0 contract evolution;
- `1.0.0`: reserved for intentionally stabilized authority/protocol/SDK contracts.

1.0 readiness requires stable compatibility commitments, a deprecation policy, hardened conformance, reproducible releases, independent security review, production-operations documentation, and meaningful external-adoption evidence.
