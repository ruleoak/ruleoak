# RuleOak community roadmap

RuleOak v0.50.0 is the starting public release. Future work is driven by observed technical needs, public compatibility commitments, and independently reported use.

## Current priorities

1. Make the Effect Boundary quickstart reliable on supported Node.js platforms.
2. Expand reviewed Effect Profiles for real consequential tool routes.
3. Improve compatibility/conformance evidence for MCP and supported adapters.
4. Strengthen candidate-change review without allowing model output to certify itself.
5. Turn reproducible external bug reports into durable tests and contracts.
6. Complete independent security review and remediate findings before any 1.0 claim.

## Evidence discipline

Repository tests establish source behavior only. Native/platform behavior, independent integrations, external security assurance, adoption and retention require separate observed evidence. Unknown or unmeasured outcomes remain explicit.

## 1.0 readiness

A 1.0 release requires stable public contracts, reproducible and attested releases, mature conformance, independent security review, documented operations, and meaningful external use. No date is promised.
