# Publication identity

The official publisher and project steward for the RuleOak v0.50.0 public repository is **RuleOak Pte. Ltd.**.

Public-facing repository metadata, package author fields, citation metadata, first-party notices and SPDX copyright headers use that corporate identity. Personal founder names and collective placeholder identities are not used as the official publisher identity.

This publication metadata does not erase third-party ownership, third-party notices or rights attached to external contributions. Those remain governed by their applicable licenses and contribution history.
