# Changelog

RuleOak v0.50.0 is the starting public release.

## v0.50.0 — public preview

- Open-source Apache-2.0 `@ruleoak/protocol`, `@ruleoak/core`, and `@ruleoak/cli`.
- Effect Boundary for exact authorization, one-use execution authority, postcondition verification, explicit uncertainty, evidence, and safe retry decisions.
- MCP stdio and Streamable HTTP guarded paths for supported protocol traffic.
- `ExecutionLease`, `EffectReceipt`, Evidence Graph, Evidence Bundles, observation-quality semantics, and effect reconciliation.
- Inspector, capability history/watch, Effect Profiles, Flight Control, Flight Recorder, CrashLab, conformance and reliability scorecards.
- Intent-Verified Development front door for reviewing AI-produced candidate changes, including protected qualification evidence, reusable review profiles, and receipt comparison.
- Public API maturity metadata, release qualification, reproducible packaging checks, SBOM generation, GitHub Actions, security reporting, contribution guidance, and trademark policy.
- Corporate publication identity standardized on RuleOak Pte. Ltd.

Passing source tests or qualification gates does not establish external adoption, independent security certification, or universal production fitness.
